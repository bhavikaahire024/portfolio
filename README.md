# PrepWise - AI Interview Platform Frontend

A classy black-themed frontend web app for an AI interview preparation platform named **PrepWise**.

## Features
- User authentication UI with **Sign In** and **Sign Up** forms.
- Client-side auth flow using `localStorage` for demo purposes.
- Dashboard with:
  - Interview feedback highlights
  - Interview rating meter
  - Suggested interview tracks
  - Platform feature list
- Responsive dark UI with a branded PrepWise logo.

## Run
Open `index.html` directly in your browser.

> Note: This is a frontend-only demo and does not include backend APIs or secure password storage.
